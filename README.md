# rockwxp.github.io

Personal website of Xiaopeng (Rock) Wu.

The site is a dependency-free static build designed for GitHub Pages. Its current focus is robot learning for humanoid locomotion and manipulation, connecting visual teleoperation, demonstration data, and imitation learning.

## Research media

- `assets/bimanual-box-relocation.mp4`: silent, web-optimized visual teleoperation demonstration in simulation.
- `assets/act-policy-inference.mp4`: existing autonomous target interaction demonstration.
- `assets/demonstration-to-policy-pipeline.png`: lightweight diagram preview; the matching SVG provides the full-size vector version.
- `assets/humanoid-loco-manipulation-poster.pdf`: current research poster.

Videos load on demand and include descriptive captions. The page distinguishes human-operated teleoperation from autonomous policy execution.

## Local preview

Open `index.html` directly, or serve the directory with any static HTTP server.

## Publishing

GitHub Pages publishes the `main` branch at <https://rockwxp.github.io>.
