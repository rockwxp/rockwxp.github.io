# rockwxp.github.io

Personal website of Xiaopeng (Rock) Wu.

The site is a dependency-free static build designed for GitHub Pages. Its current focus is humanoid teleoperation, embodied data systems, and robotics infrastructure.

## Local preview

Open `index.html` directly, or serve the directory with any static HTTP server.

## Publishing

GitHub Pages publishes the `main` branch at <https://rockwxp.github.io>.
